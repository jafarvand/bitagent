# Exchange API artifacts

These files are the source contract used to build bitAgent version 0:

- `exchange-openapi.yaml` — pilot OpenAPI 3.0 contract
- `exchange-postman-collection.json` — signed request examples
- `exchange-api-notes.md` — backend, authentication, endpoints, samples and gaps
- `source-image.png` — source attachment retained for traceability

Known contract issues and requested endpoints are tracked in
[`../planning/mvp-v0.md`](../planning/mvp-v0.md) and
[`../decisions/0002-api-auth-v02.md`](../decisions/0002-api-auth-v02.md).
