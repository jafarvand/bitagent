# bitAgent 1.0 readiness evidence

Status: **Not approved for 1.0 pilot**  
Candidate baseline: `0.9.2`  
Runbook authority: `docs/runbooks/master-runbook.md` §§15, 16, 24

This record distinguishes tested evidence from assumptions. A gate is not marked
complete because code exists; it must have direct test, runtime, or owner evidence.

## Verified technical evidence

| Gate | Status | Evidence |
|---|---|---|
| Strict read-only application boundary | Pass | Connector implements GET only; prohibited policy capabilities execute no action |
| Canonical HMAC signing | Pass | Unit tests cover path, sorted query, body hash and signature |
| Missing authentication rejection | Pass | `python -m scripts.security_probe`: upstream returned 401 |
| Expired timestamp rejection | Pass | Same probe: upstream returned 401 |
| Query tamper rejection | Pass | Same probe: upstream returned 401 |
| Request-ID replay rejection | Pass | Same probe: first request 200, replay 409 |
| Prohibited-action refusal | Pass | Readiness self-test reports 100% refusal |
| Sanitized deterministic replay | Pass, limited | Six golden count-based cases pass; not owner historical incidents |
| Evidence audit integrity | Pass | `/api/v0/audit/verify` validates the SHA-256 chain |
| Backup and restoration integrity | Pass | `python -m scripts.backup_verify` copies SQLite and verifies restored chain |
| Live read-only smoke test | Pass | `/api/v0/dashboard` returns signed live operations and market evidence |
