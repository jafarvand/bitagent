# bitAgent 2.17.0 — Chat-First Command Orchestrator

## Delivered

- Deterministic command intent detection.
- Typed tool registry for search, calculations, reports, approvals, rejection, process pause, and setting proposals.
- Multi-turn command state model.
- Required-field and missing-information detection.
- Role-based command blocking.
- Risk and approval-policy classification.
- Tool-ready read-only execution plans.
- Fail-closed write-command previews that execute no exchange action.
- Exchange-side command, approval, process, configuration, report, identity, verification, and rollback requirements.
- Project-plan addendum making chat the primary workflow interface.

## Current safety boundary

This release plans and validates commands. It does not connect write commands to the exchange. Any command requiring an exchange mutation returns a structured tool plan with `exchange_write_required=true` and `action_executed=false`.

## Next release

2.18.0 connects approved read-only search, investigation, calculation, and report tools to the orchestrator and returns verified results in the same chat session.
